# ads.txt — Authorized Digital Sellers
# =====================================================================
# This file tells ad networks (like Google AdSense) which accounts are
# authorized to sell ads on this site. It must be accessible at:
#   https://yourdomain.com/ads.txt
#
# Format (one line per authorized seller):
#   <domain>, <publisher-id>, <relationship>, <certification-authority-id>
#
# Example for Google AdSense (fill in your publisher ID after approval):
#   google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
#
# Steps:
#   1. Apply for AdSense at https://adsense.google.com
#   2. Get your publisher ID (starts with "pub-")
#   3. Uncomment and update the line below with your ID
#   4. Redeploy
#
